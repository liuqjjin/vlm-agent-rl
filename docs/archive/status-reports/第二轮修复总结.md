## 关键设计决策

### Navigation 数据划分逻辑
由于 Navigation 使用 `seed % len(dataset)` 且数据集只有 60 个任务：
- **不可能** 有互斥的 train/val/test
- **实际方案：** Test 使用与 train 相同的任务（seeds 0-29）
- **验证策略：** Val (seeds 30-59) 是唯一真正 held-out 的集合，用于选 checkpoint
- **Test 目的：** 测量学习后策略在训练任务上的泛化性能

这不是数据泄露，而是明确的 **in-distribution generalization test**。

### Validation padding 的正确语义
- Padding 是整条轨迹的复制，不是单个 turn
- Sentinel 必须在输入时标记，并传播到所有输出 turns
- 过滤时删除整条 padding 轨迹的所有 turns
- 保留所有非 padding 轨迹的所有 turns
