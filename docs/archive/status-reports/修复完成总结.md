## ✅ 已修复的阻塞问题

### 1. Actor update_policy 的 NameError（P0）
- **问题：** 使用 episode GRPO 时，`policy_weights` 分支调用 `core_algos.apply_policy_loss_weights` 但模块未导入

- **测试：** 新增 `test_policy_weights_integration.py` 验证完整调用链

### 2. Navigation validation padding 副本（P0）
- **问题：** 30 samples / 8 workers 产生 2 个 padding 副本，原代码用 `group_idx` 无法识别
- **修复：** 在输出中添加 `request_id`，过滤时跟踪已见 ID，只保留首次出现
- **测试：** 新增 `test_validation_padding.py` 验证去重逻辑

### 3. AutoDL bootstrap 清洁（P0）
- **问题：** FlashAttention wheel 残留，环境名不一致，可能产生 dirty worktree
- **修复：** 统一环境名为 `vagen`，安装后删除 wheel，结束前重置 verl 子模块
- **文件：** `scripts/autodl_bootstrap.sh`

### 4. Train/Val/Test 数据重叠（P0）
- **问题：**
  - Sokoban: val [10001, 10256] 与 test [10001, 10128] 重叠
  - Navigation: val [30, 59] 与 test [30, 59] 完全相同
- **修复：**
  - **Sokoban:** Train [1, 10000], Val [10001, 10128], Test [10129, 10256]
  - **Navigation:** Train [0, 29], Val [30, 59], Test [60, 89]
- **测试：** 新增 `test_data_splits.py` 验证互斥性
