# 历史状态报告（SUPERSEDED）

本目录保存项目迭代过程中的历史审计与修复报告。它们反映撰写当时的判断，其中的测试数量、seed、成本、命令和“完成”结论可能已经失效。

使用规则：

- 当前项目状态只查看仓库根目录的 [`PROJECT_STATUS.md`](../../../PROJECT_STATUS.md)。
- 正式实验配置只查看 [`experiments/matrix.yaml`](../../../experiments/matrix.yaml) 与 [`EXPERIMENTS.md`](../../../EXPERIMENTS.md)。
- GPU 规划只查看 [`PREDICTED_METRICS.md`](../../../PREDICTED_METRICS.md)。
- 本目录文件不得作为简历、README、GPU 执行或项目完成判断的证据。

保留这些文件是为了展示审计过程和错误修订历史，不表示继续支持其中的命令。
